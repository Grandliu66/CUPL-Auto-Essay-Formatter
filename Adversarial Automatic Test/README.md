# 对抗式自动测试（Adversarial Automatic Test）

本目录是针对排版引擎（`essay_tool`）的自动化测试框架。其目标是把测试结果的判定标准从人工逐条核对，替换为对《工具操作逻辑》规则表的机器比对，使回归测试不必依赖人工目测。

## 判据来源

`essay_tool/gui/operation_logic_text.py` 中的 `OPERATION_LOGIC_TEXT`，即图形界面内"工具操作逻辑"窗口显示的正文，是本框架全部判定的唯一依据。项目 `docs/` 目录下与判定逻辑相关的文档仅作参考，不参与自动判定，因为其内容可能落后于窗口正文。

## 测试层次

`run_aat.py` 将下列十层整合为一条跑批命令：

1. 写法层（`gen_matrix.py`）：将识别规则的判据维度成对展开为具体段落样本，逐条比较规则表给出的判据与引擎的实际识别结果。
2. 结构层（`gen_structure.py`）：对文档结构部件做缺席、重复、错序等组合穷举，检验识别结果与规则的一致性。
3. 产物层（`gen_pipeline.py`）：对 docx 包做合法但反常的重排，运行完整排版流程并连续执行多次，检查是否崩溃、产出是否可正常打开、多次运行结果是否一致。
4. 产物不变量（`gen_invariant.py`）：核查排版产物中源文档可识别的部件是否完整保留、顺序是否保持一致。
5. 期望对拍（`_rerun_all.py`）：对一批测试文档执行识别与比对，报告与期望结果不一致的文档。
6. 告警对拍（`aat_alerts.py`）：核对程序在处理测试文档时应当触发的提示文案与实际触发情况是否一致。
7. 告警边界（`_check_alerts_edge.py`）：核对提示信息在边界条件下是否按规则触发或不触发。
8. 断言层（`aat_asserts.py`）：针对若干不经过识别流程比对的加工逻辑，直接检查排版产物是否符合预期。
9. 例外层（`gen_exceptions.py`）：从识别规则中"允许的例外"条款生成样本，检验引擎对这些例外情形的处理。
10. 等价层（`gen_equiv.py`）：验证写法上等价的输入（如不同的编号符号写法）是否得到字节级一致的输出。

## 基础组件

- `rules_parser.py`：将《工具操作逻辑》窗口正文中的表格解析为结构化的规则数据，并对表格本身做一致性检查，包括列数、重复项与必填项缺失。
- `aat_docx.py`：将一份 docx 文件解析为逐段落的实际内容与格式，包括文字、样式、直接格式、域、图片、表格、页眉页脚、脚注与分节信息。
- `aat_diff.py`：比较两份 docx 文件，或比较一份 docx 与一组期望值，输出定位到具体段落的差异报告。
- `aat_expect.py`：根据识别规则的字面判据计算每个段落应当被识别成的身份，并与引擎的实际识别结果比较。
- `aat_scan.py`：逐个切换预设中的单个设置项、重新排版并比较结果，判断该设置项是否实际生效，以及生效范围是否符合声明。
- `aat_coverage.py`：枚举预设与流程中全部可调整的设置项，核对单项扫描是否已覆盖。
- `scan_all.py`：对一批测试文档批量执行单项扫描，汇总各设置项分别在哪些文档上被触发。

## 设计约束

- 期望结果的判据只能来自规则表的字面文字，不参照引擎的具体实现推导，以保证比对不会退化为程序与自身的比较。
- 每条判据标注其对应的规则编号，差异报告中同样标注该编号，便于按编号查阅规则原文。
- 比对结果只报告差异本身，不对差异应如何处理作出判断。
- 断言只来自规则表或明确的产品设计，不从程序当前的运行结果反推。

## 与主程序的关系

本框架只读取 `essay_tool` 模块提供的接口，例如 `pipeline.run()` 与 `detect` 模块，不修改其内容。运行产生的全部报告写入本目录下的 `_out/` 子目录，不纳入版本控制。

## 运行方式

```powershell
# 解析规则表并做一致性体检
.venv\Scripts\python.exe "Adversarial Automatic Test\rules_parser.py"

# 跑完全部十层，返回非零退出码表示存在问题
.venv\Scripts\python.exe "Adversarial Automatic Test\run_aat.py"

# 跳过耗时最长的产物层
.venv\Scripts\python.exe "Adversarial Automatic Test\run_aat.py" --quick

# 对单份文档做设置项扫描
.venv\Scripts\python.exe "Adversarial Automatic Test\aat_scan.py" <docx 路径> --list

# 比较两份 docx 文件
.venv\Scripts\python.exe "Adversarial Automatic Test\aat_diff.py" <docx 路径 1> <docx 路径 2>
```

## 扫描结果标记

`aat_scan.py` 与 `scan_all.py` 的输出使用下列标记：

| 标记 | 含义 |
|---|---|
| 有效 | 该设置项生效，且影响范围符合声明 |
| 已知耦合 | 生效，但变化来自已登记的关联关系 |
| 未见变化 | 该设置项在这份测试文档上未产生可观察的变化 |
| 越界 | 该设置项影响了声明范围之外的内容 |

## 目录内容

- `发现/`：确认过的现象记录及其复现材料。
- `_fixtures/`：专用测试文档。
- `_out/`：运行产生的报告，不纳入版本控制。
