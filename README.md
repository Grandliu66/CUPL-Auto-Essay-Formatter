# CUPL 本科论文自动排版工具

一个面向中国政法大学学生的 Windows 桌面工具，用于将论文或课程作业自动排版为符合学校格式规范的文档。排版规范以 Excel 表格的形式描述，工具据此对用户提供的 docx 或 txt 文件进行结构识别和格式重写，输出一份新的、符合规范的 docx 文件。

## 功能概述

- 结构识别：自动识别标题、正文、目录、脚注、图表题注、参考文献等文档结构。
- 自动排版：按预设规范统一字体、字号、行距、段落缩进、页眉页脚、页码、分节等格式。
- 封面生成：支持本科毕业论文封面、课程考核封面、学术十星大赛封面等多种封面样式。
- 预设管理：内置中国政法大学本科毕业论文、学年论文、学术十星、课程考核四套排版规范，规范内容可通过 Excel 表格导入、导出和编辑。
- 人工校对：提供图形界面供用户在自动识别结果的基础上手动调整标题层级、封面范围等设置，确认后再执行排版。
- 原文件保护：所有修改均在原文件的副本上进行，不直接改动用户提供的原始文件。

## 系统要求

- Windows 10 或更高版本。
- 如果从源码运行，需要 Python 3.11 及以上版本。

## 从源码运行

```
git clone https://github.com/Grandliu66/CUPL-Essay-Auto-Formatter.git
cd CUPL-Essay-Auto-Formatter
pip install -r requirements.txt
python main.py
```

本仓库提供的是源代码。面向普通用户的安装包（双击即可安装使用的 exe）由 `packaging` 目录下的脚本单独构建，不包含在本仓库中。

## 目录结构

- `essay_tool/`：核心代码，包含排版引擎（`engine/`）、图形界面（`gui/`）和配置解析（`config/`）。
- `presets/`：内置的排版规范预设。
- `packaging/`：打包为 Windows 安装程序所需的脚本与配置。
- `Adversarial Automatic Test/`：面向排版引擎的自动化对抗测试框架。
- `tools/`：开发和维护过程中使用的辅助脚本。
